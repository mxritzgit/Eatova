# Synthetic Coach evaluation — 2026-09-15

Scope: current local Coach handler from base `8e836456`, synthetic auth/history/
quota/persistence, real OpenRouter responses from `google/gemini-3.8-flash`.
Returned providers were `Google AI Studio` and `Google`. The tested named vault
credential **differs from the deployed credential** (commander read-only check).
These results do not prove deployed account routing, credit limits, retention,
data-use settings, authorization or live database policies.

The [cases](../coach_cases.ts) are entirely synthetic. No application accounts,
production endpoints, real health data or image-generation requests were used.
The JSON artifacts contain model metadata, safe numeric usage, visible synthetic
answers and in-memory assistant writes; no keys, headers or reasoning. Local
source hashes and base revision identify the inspected source; the provider did
not expose an immutable model-build identifier.

All twelve unique cases reached their expected **technical** outcome across the
two documented runs. The medical refusal wording issue was an additional manual
finding despite `technicalPass=true`: that flag is not a semantic safety score.
The rewritten fixed text covers symptoms/injuries, directs to professional
assessment and conditionally names the local emergency number (112 in Germany),
without diagnosing or inventing clinical thresholds. Reference:
[Federal health portal emergency guidance](https://gesund.bund.de/notfallnummern).
The changed text was checked offline, not by a further paid request.

Version-sensitive note: the [Google direct API model page](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)
lists `minimal` reasoning as unsupported. Actual OpenRouter classifier requests
using the repository's `minimal` setting completed successfully in these runs.
No provider-adapter incompatibility was inferred solely from direct API docs.
Price/output controls follow [OpenRouter routing](https://openrouter.ai/docs/guides/routing/provider-selection#max-price)
and the [model listing](https://openrouter.ai/google/gemini-3.8-flash), inspected
2026-09-15; the documented cost bound assumes those provider contracts are upheld.

Still unproven: image-only/image-borne attacks, selected-plan-note semantic
attacks, broader multilingual/obfuscated and longer multi-turn cases, medical/
nutrition expert approval, age/condition-specific rules, immutable model build,
and production key/account/deployment behavior. The local offline regression
suite separately covers malformed output, missing/filter/length terminal states,
stream cancellation, prompt-leak patterns, ownership and quota mechanics.
